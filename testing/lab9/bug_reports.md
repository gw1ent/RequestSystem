# Отчёт о дефектах

## Результат тестирования

**Дефектов не обнаружено.**

В ходе функционального тестирования RequestSystem выявленных дефектов не зафиксировано. Проверенные сценарии завершились ожидаемыми результатами.

## Проведённые проверки

В ходе тестирования были проверены следующие группы сценариев:

1. **Позитивные проверки:**
   - создание заявки;
   - просмотр заявки;
   - поиск заявки;
   - редактирование описания заявки;
   - изменение статуса заявки.

2. **Негативные проверки:**
   - отправка формы с незаполненными обязательными полями;
   - отправка запроса с некорректным форматом данных;
   - обращение к несуществующей заявке.

3. **Граничные проверки:**
   - проверка минимальной длины темы;
   - проверка максимальной длины темы;
   - использование специальных символов в теме заявки.

4. **Проверки ролей и прав доступа:**
   - проверка доступа неавторизованного пользователя;
   - проверка запрета операции для пользователя без необходимых прав.

5. **Интеграционные проверки интерфейса и базы данных:**
   - создание заявки через интерфейс и проверка сохранения после обновления страницы;
   - изменение описания заявки и проверка сохранения результата после обновления страницы.

6. **Проверки API:**
   - получение списка категорий;
   - изменение категории;
   - создание категории;
   - удаление категории.

## Подтверждающие материалы

В качестве доказательств проведения тестирования приложены скриншоты интерфейса и ответов API.

Материалы находятся в каталоге `screenshots/` и приложены к отчёту о результатах тестирования.

## Итог

По результатам проведённых проверок дефекты не обнаружены. Регистрация и повторная проверка исправлений не требовались, поскольку исправляемых дефектов не выявлено.
